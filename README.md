# Hyewon Yang — Portfolio

카테고리별로 구성한 개인 포트폴리오 웹사이트입니다.

## Categories
- **About** — 소개 및 관심 분야
- **Research & Activities**
  - Certificate — 자격증 및 수료 내역
  - Activities — 교내외 활동
  - Research & Projects — 연구 및 프로젝트
- **AI-Generated Reports** — AI·데이터 기반 보고서 및 대시보드

## Structure
```
.
├── index.html
├── about/
├── research-activities/
│   └── certificate/
├── activities/
├── research-projects/
├── ai-reports/
└── assets/
    ├── css/style.css
    └── js/main.js
```

## Run locally
정적 웹사이트이므로 `index.html`을 브라우저에서 열거나 GitHub Pages/Vercel에 배포할 수 있습니다.
